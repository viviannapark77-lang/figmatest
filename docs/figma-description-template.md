# Figma 기획문서 Description 템플릿

Figma 기획문서(화면 스펙) 노드를 읽을 때, 그 안의 "Description" 표 내용을 옮겨 적기 위한
빈 템플릿이다. 컴포넌트 구현 전 Clarify 단계에서 채운다. 구현 후 산출물인
`<Component>.design.md`(Figma 소스 + 토큰 매핑)와는 다른 문서다 — 이 문서는 요구사항 자체를,
`.design.md`는 구현 근거를 담는다.

## 사용법

1. Figma 기획문서 노드를 읽는다 (`get_metadata` → `get_screenshot`).
2. 아래 표를 그대로 복사해 `docs/description/<화면ID>.md` 등에 붙여넣고 채운다.
3. Description 행은 Figma 문서에 있는 개수만큼 추가·삭제한다. 01/02/03은 예시 개수일 뿐이다.
4. "확인 필요 사항"이 비어 있지 않으면, 구현으로 넘어가기 전에 요청자에게 먼저 확인한다 (원칙 1).
